🚀 Highlights of My Work
1. Edge AI Development Environments (Assignment 1)
An analysis of the foundational ecosystem required for Edge AI, including research into VS Code, TensorFlow Lite, and Edge Impulse.
Key Insight: Learned how tools like GitHub Copilot and Node.js create a cohesive pipeline for IoT development.
2. Model Deployment Concepts (Lab 2)
A conceptual deep dive into the MNIST Neural Network architecture and the process of converting standard models into .tflite files for resource-constrained hardware.
Key Insight: Explored the importance of Quantization in reducing model size without significantly impacting accuracy.
3. Real-Time Video Analytics Case Study (Assignment 2)
A detailed evaluation of the "Liverpool Smart Pedestrians" project, which utilized NVIDIA Jetson TX2 hardware and YOLO V3 algorithms for privacy-compliant traffic monitoring.
Key Insight: Analyzed how edge computing enables smart city infrastructure while maintaining 100% data privacy.
