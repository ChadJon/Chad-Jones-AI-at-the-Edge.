# Assignment 1: Understanding Development Environments for Edge AI and IoT

## The Problem
Before diving into building Machine Learning models, it is essential to understand the "Edge Intelligence" landscape. The goal of this assignment was to research and analyze the foundational tools required to bridge the gap between high-level machine learning and low-level hardware.

## My Approach
I conducted a deep dive into the following ecosystem components:
*   **IDEs:** Visual Studio Code and its role in remote development.
*   **Runtimes:** Node.js for managing real-time IoT data traffic.
*   **Platforms:** Edge Impulse CLI for "TinyML" development.
*   **Frameworks:** TensorFlow Lite for optimized inference on low-power hardware.
*   **Cloud Tools:** Google Colab for GPU-accelerated model training.
*   **Generative AI:** Using GitHub Copilot to accelerate embedded coding.

## What I Learned
Through this report, I learned how these tools form a cohesive "pipeline." I now understand that Edge AI isn't just about the model, but about how that model is quantized, containerized, and deployed to a physical device to reduce latency and improve privacy.
