# Assignment 3: IIoT Forecasting & Generative Modeling Presentation

## Project Overview
This project focuses on the intersection of Industrial IoT and predictive analytics. The presentation details the methodology used to transform raw, high-frequency sensor data into reliable daily insights using advanced forecasting and generative modeling techniques.

## Presentation Highlights
*   **The Challenge:** Managing irregular sampling and environmental noise in 97,000+ IoT records.
*   **The AutoML Advantage:** Justification for using **Nixtla StatsForecast** over traditional deep learning for computational efficiency.
*   **Generative AI Integration:** How a Variational Autoencoder (VAE) was used to augment the training set with synthetic samples.
*   **Key Results:** Achieving high-accuracy temperature forecasting suitable for industrial monitoring and predictive maintenance.
